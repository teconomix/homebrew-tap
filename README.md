# teconomix Homebrew tap

```bash
brew install --cask teconomix/tap/local-transcriber
```

**[Local Transcriber](https://transcriber.teconomix.net)** – transcribe meetings, calls and dictation locally on your
Mac, with speaker recognition. No cloud, no account. Apple Silicon, macOS 14 or newer.
Source: [teconomix/local-transcriber](https://github.com/teconomix/local-transcriber) (MIT).

The cask runs the project's own installer (checksums verified); `brew upgrade` updates, `brew uninstall
local-transcriber` removes the app (recordings and transcripts in `~/Transcriber` are kept).
